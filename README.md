# passwordepic.com

The public site for the PasswordEpic Android app — landing page, the legal
pages Google Play requires, and the user guide. Built with **Docusaurus 3**.

```
npm install
npm start          # dev server on :3000
npm run build      # must pass before pushing; CI runs the same command
```

| Route | Source |
|---|---|
| `/` | `src/pages/index.tsx` |
| `/privacy` | `src/pages/privacy.md` — **Google Play fetches this** |
| `/terms` | `src/pages/terms.md` |
| `/support` | `src/pages/support.md` |
| `/docs/*` | `docs/` — sidebar is autogenerated from the folder |

Images go in `static/img/` and are referenced as `/img/name.png`. Everything
under `static/` is copied to the site root, including `CNAME`.

`trailingSlash: true` is deliberate: it emits `privacy/index.html` instead of a
flat `privacy.html`, so `/privacy` resolves on any static host rather than
relying on the host guessing an extension.

## Deploy

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds and
publishes to GitHub Pages.

One-time repo setup: **Settings → Pages → Source: GitHub Actions**.
